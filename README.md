# 台股選股分析系統

一個幫助投資台灣股票的分析工具，透過技術指標、法人籌碼、價量關係等面向評分，篩選適合買進的股票。

## 功能特色

- **多元評分系統**：結合技術面、籌碼面、價量、支撐壓力
- **技術指標**：RSI、MACD、KD、均線、乖離率
- **法人追蹤**：外资、投信、自營商買賣超
- **價量警示**：漲跌停監控、爆量警示
- **支撐壓力**：自動計算關鍵價位

## 安裝需求

```bash
pip install requests pandas numpy
```

## 執行方式

### 互動選單模式（推薦）

```bash
py main.py
```

執行後會顯示選單：
```
==================================================
台股選股分析系統
==================================================
1) 分析全部股票
2) 依類型選擇
3) 隨機選取 50 檔

請選擇 (1/2/3): 
```

### 命令列參數模式

```bash
# 分析全部股票
py main.py -m all

# 隨機選取 50 檔
py main.py -m random

# 依類型選擇 (1=半導體, 2=電子, 3=金融, 4=水泥/化工, 5=ETF, 6=鋼鐵/營建, 7=航運, 8=其他)
py main.py -m category -c "1,2"

# 類型 + 額外指定個股
py main.py -m category -c "1" -s "2330,2317"

# 限制分析數量
py main.py -m random -n 30
```

### 參數說明

| 參數 | 說明 |
|------|------|
| `-n` | 分析股票數量（預設全部） |
| `-m` | 模式：all/random/category |
| `-c` | 類型代碼（逗號分隔） |
| `-s` | 額外指定的股票代碼 |
| `-r` | 隨機模式數量（預設50） |

## 問題排除

### Q: 執行時顯示「無即時數據」
A: 這可能是 API 延遲，開盤後一段時間會正常顯示。

### Q: 想加入新的股票
A: 請編輯 `stock_list.py` 檔案，在 STOCK_LIST 中加入。

### Q: 分析很慢
A: 可以用 `-n` 參數限制分析數量，例如 `-n 30` 只分析 30 檔。

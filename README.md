# 台股選股分析系統

透過技術指標、法人籌碼、價量關係、支撐壓力四大面向自動評分，篩選適合買進的台股。使用網頁介面操作，不需要懂程式。

---

## 快速開始

**第一次使用請直接雙擊 `啟動.bat`**，它會自動安裝所有需要的套件並開啟網頁。

```
雙擊 啟動.bat → 自動安裝 → 瀏覽器自動開啟 → 開始使用
```

> 需要先安裝 [Python 3.9+](https://www.python.org/downloads/)，安裝時記得勾選「Add Python to PATH」

---

## 功能介紹

### 評分系統

| 分數 | 等級 | 建議 |
|------|------|------|
| ≥ 25 | 🔥 強買 | 積極買入 |
| 15–24 | ✓ 買進 | 可以考慮 |
| 8–14 | ○ 觀望 | 謹慎觀察 |
| < 8 | × 不建議 | 風險較高 |

### 四大評分面向

| 面向 | 預設權重 | 指標 |
|------|----------|------|
| 技術面 | 30% | RSI、KD、MACD、布林通道、均線 |
| 籌碼面 | 30% | 外資、投信、自營商買賣超 |
| 價量 | 25% | 成交量、漲跌幅、價量配合 |
| 支撐壓力 | 15% | 關鍵支撐位、壓力位 |

### 網頁功能

- **📋 推薦清單**：依評分排序，含評分長條圖（可橫向捲動）
- **📊 技術指標**：前10名的 RSI / KD / MACD / 布林位置
- **🏛 外資籌碼**：三大法人買賣超柱狀圖（可橫向捲動）
- **🚨 漲跌停**：即時漲停、接近漲停、跌停監控
- **🔍 詳細理由**：強買股票的完整訊號說明

## 側邊欄設定說明

| 設定 | 說明 |
|------|------|
| 分析模式 | 全部股票 / 依類別 / 隨機抽樣 |
| 評分權重 | 自訂各面向比重（自動正規化，總和不必是100） |
| 最低評分顯示 | 過濾掉低分股票，例如只看 ≥ 15 分 |
| 顯示筆數 | 最多顯示幾筆結果 |
| 黑名單 | 輸入不想分析的股票代碼，逗號分隔（例：2330,2317） |
| 最低成交量 | 更新股票清單時過濾冷門股，預設 1000 張 |

## 第一次使用流程

1. 雙擊 `啟動.bat`，等待安裝完成（第一次較久，約 1–2 分鐘）
2. 瀏覽器開啟後，點左側「**更新清單**」按鈕，等待股票清單下載完成
3. 選擇分析模式（建議先用「隨機抽樣 50 檔」測試）
4. 點「**▶ 開始分析**」，等待進度條完成
5. 切換上方 Tab 查看各種分析結果

> **注意**：分析全部股票（約 1000+ 檔）需要 10–20 分鐘，建議先用隨機抽樣測試。

## 常見問題

**Q：雙擊 `啟動.bat` 閃一下就關掉了？**
A：通常是 Python 沒有加入 PATH。重新安裝 Python，安裝頁面記得勾選「Add Python to PATH」。

**Q：股票清單是空的？**
A：點側邊欄的「更新清單」按鈕，等 API 抓取完成（約 30 秒）。

**Q：分析結果全部是 0 分？**
A：可能是非交易時間，API 沒有即時資料。開盤時間（09:00–13:30）分析最準確。

**Q：分析很慢或卡住？**
A：建議先用「隨機抽樣」模式測試。分析全部股票時 API 有速率限制，需要耐心等待。

**Q：側邊欄不見了？**
A：按 `Ctrl+Shift+R` 強制重新整理頁面，或重新開無痕視窗。

# 台股選股分析系統

一個幫助投資台灣股票的分析工具，透過技術指標、法人籌碼、價量關係等面向評分，篩選適合買進的股票。

## 功能特色

- **多元評分系統**：結合技術面、籌碼面、價量、支撐壓力
- **技術指標**：RSI、MACD、KD、均線、乖離率
- **法人追蹤**：外國法人、投信、自營商買賣超
- **價量警示**：漲跌停監控、爆量警示
- **支撐壓力**：自動計算關鍵價位
- **參數設定**：可自訂評分門檻、RSI 參數、篩選條件、黑名單/白名單
- **平行處理**：支援多執行緒加速分析

## 安裝需求

```bash
pip install requests pandas numpy
```

## 執行方式

### 互動選單模式（推薦）

```bash
py main.py
```

執行後會顯示選單：
```
==================================================
台股選股分析系統
==================================================
1) 分析全部股票
2) 依類型選擇
3) 隨機選取 50 檔
4) 參數設定
5) 查詢今日股票清單 (從TWSE API)
6) 匯出股票清單檔案
7) 離開

請選擇 (1/2/3/4/5/6/7): 
```

### 第一次使用

1. 首次執行請先選擇 **選項 6** 匯入股票清單
2. 匯入後會建立 `stock_cache.json` 檔案
3. 以後執行選項 1 分析時會直接讀取現有清單，不會覆蓋

### 命令列參數模式

```bash
# 分析全部股票
py main.py -m all

# 隨機選取 50 檔
py main.py -m random

# 依類型選擇 (1=半導體, 2=電子, 3=金融, 4=水泥/化工, 5=ETF, 6=鋼鐵/營建, 7=航運, 8=其他)
py main.py -m category -c "1,2"

# 類型 + 額外指定個股
py main.py -m category -c "1" -s "2330,2317"

# 限制分析數量
py main.py -m random -n 30
```

### 參數說明

| 參數 | 說明 |
|------|------|
| `-n` | 分析股票數量（預設全部） |
| `-m` | 模式：all/random/category |
| `-c` | 類型代碼（逗號分隔） |
| `-s` | 額外指定的股票代碼 |
| `-r` | 隨機模式數量（預設50） |

## 參數設定說明

選項 4 提供以下設定：

1. **評分門檻**：強買/買進/觀望的分數門檻
2. **RSI 參數**：超賣、超買、週期設定
3. **篩選條件**：最低股價、最低成交量
4. **黑名單管理**：排除特定股票
5. **白名單管理**：只分析特定股票
6. **平行處理**：啟用多執行緒加速

## 問題排除

### Q: 執行時顯示「找不到股票清單」
A: 請先選擇選項 6 匯入股票清單，建立 stock_cache.json 檔案。

### Q: 執行時顯示「無即時數據」
A: 這可能是 API 延遲，開盤後一段時間會正常顯示。

### Q: 想更新股票清單
A: 請選擇選項 6 重新匯入，會更新 stock_cache.json。

### Q: 分析很慢
A: 可以用選項 4 啟用平行處理，或用 `-n` 參數限制分析數量。
### Q: 無分析結果
A: 使用平行處理執行大量分析，api會暫停停止，請稍等20分鐘後並關掉平行處理後再嘗試。
